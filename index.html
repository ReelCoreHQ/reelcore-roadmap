完成状态如何更新？

只有合入 main 的 PR，明确列出功能编号并附带验收记录，才会标记完成。普通合并不会自动完成整阶段；仅通过旧兼容层测试，也不代表新核心已完成。

当前范围不包含已跳过条目。RC08 三项按用户要求跳过，保留编号及历史记录，不视为长稳通过；当前 G2 由 RC07 的 A08/A09 承担。范围状态优先于历史完成记录。

回退或重新打开的功能会恢复为待实现，历史合并记录继续保留。RC10 通过原生 API 适配 IYUU，完成本地验收并准备后续上游 PR 材料；旧数据迁移不在计划内。

看板公开展示计划与状态；实现代码和验收报告可能需要仓库访问权限。公开页面不包含私有源码、PR 正文或运行凭据。
